# Development Workflow Guide

This guide explains how to work efficiently with the Transfinite Ordinal Calculator codebase.

## Quick Start

```bash
# First time setup
npm install

# Start development
npm run dev
```

Then open http://localhost:3000 in your browser.

---

## Development Modes

### 🚀 Development Mode (RECOMMENDED)

**Use this for daily development - changes appear instantly!**

```bash
npm run dev
```

**What it does:**
- Starts Vite dev server at `http://localhost:3000`
- **Hot reload** - changes to `src/` files appear instantly in browser
- **No rebuild needed** - Vite compiles on-the-fly
- **Fast** - changes visible in ~100ms

**When to use:**
- Writing code
- Testing changes
- Debugging
- Iterating on features
- **Alertness testing** (instant feedback on RuleEngine changes!)

**Test files for dev mode:**
- Open `http://localhost:3000` for main calculator
- For tests, open original files (`tests/ordinal_enf_test.html`) which load individual .js files from root
- OR use dev server directly in test files (see below)

### 📦 Production Build Mode

**Use this rarely - only when preparing for deployment.**

```bash
npm run build     # Build optimized bundle to dist/
npm run preview   # Preview the production build
```

**What it does:**
- Compiles all `src/` files
- Bundles into single optimized `dist/assets/bundle.js` (118KB)
- Minifies code
- Generates source maps

**When to use:**
- Before deploying to GitHub Pages
- Testing production bundle
- Measuring bundle size
- Final verification before release

**Test files for production mode:**
- `tests/ordinal_calculator_test_new.html` - loads `dist/assets/bundle.js`
- `tests/ordinal_enf_test_new.html` - loads `dist/assets/bundle.js`

## Recommended Workflows

### For Daily Development

```bash
# Terminal 1: Start dev server (leave running)
npm run dev

# Make changes to src/ files in your editor
# → Browser auto-updates instantly!
# → No rebuild command needed!
```

**Testing your changes:**
1. Open http://localhost:3000
2. Test calculator functionality
3. Check browser console for errors
4. For comprehensive tests, use legacy test files:
   - Open `tests/ordinal_enf_test.html` (loads root .js files)
   - OR manually test specific functionality

### For Testing Alertness/Specific Features

When you want to test something like alertness:

```bash
# 1. Edit src/operations/RuleEngine.js
#    Set: static alertnessTestEnabled = true;

# 2. Dev server auto-reloads (if npm run dev is running)
#    OR reload browser if viewing localhost:3000

# 3. Test immediately - no build needed!
```

### Before Committing/Deploying

```bash
# 1. Make sure all changes work in dev mode
npm run dev
# Test thoroughly...

# 2. Build production bundle
npm run build

# 3. Test production build
npm run preview
# Open test files: tests/ordinal_calculator_test_new.html

# 4. If all tests pass, commit
git add .
git commit -m "Your changes"
git push
```

## Development Server Details

### Vite Dev Server Features

**Hot Module Replacement (HMR):**
- Edit `src/*.js` → changes appear instantly
- Browser state preserved
- No page reload for most changes
- Extremely fast (<100ms)

**Access points:**
```
http://localhost:3000/              # Main calculator (index.html)
http://localhost:3000/src/main.js   # Entry point (for test files)
```

**How it works:**
- Vite serves files directly from `src/`
- Transforms ES6 modules on-the-fly
- No bundling (faster)
- Source maps for debugging

### Production Build vs Dev Server

| Feature | Dev Server | Production Build |
|---------|-----------|------------------|
| **Speed** | Instant | 300-400ms |
| **Iteration** | Edit → See change | Edit → Build → Refresh |
| **Bundle** | No bundling | Optimized 118KB |
| **Source Maps** | Always | Yes |
| **Minified** | No | Yes |
| **File Size** | Larger | Smaller |

## Troubleshooting

### "Changes aren't appearing"

**If using dev server (localhost:3000):**
- Changes should appear instantly
- If not, check terminal for errors
- Try hard refresh: Ctrl+Shift+R

**If using production tests:**
- You need to rebuild: `npm run build`
- Then refresh browser
- This is expected - use dev mode instead!

### "Module not found errors"

- Check that npm run dev is running
- Check file paths in import statements
- Remember to use `.js` extension in imports

### "Tests not running"

**Legacy test files** (`tests/ordinal_enf_test.html`):
- Load from root .js files
- Don't need dev server or build
- Open directly in browser

**New test files** (`tests/*_new.html`):
- Load from `dist/assets/bundle.js`
- Need `npm run build` first
- Use for production testing only

2. `tests/ordinal_calculator_test.html` - Basic calculator functionality

6. `tests/simplify_test.html` - Ordinal simplification with budget constraints
7. `tests/is_well_formed_test.html` - Validate ordinal structure correctness

**Debug & Diagnostic Tools** (2 tools):
1. `tests/conversion_debug.html` - Visual conversion matrix and dependency graph
2. `tests/finverse_debug.html` - Debug ordinal-to-real mapping inverse function

All test files load from `/src/main.js` using ES6 modules via the Vite dev server.

Access all tests via: `http://localhost:3000/index-tests.html`

This provides a visual interface to launch any test file with descriptions.
