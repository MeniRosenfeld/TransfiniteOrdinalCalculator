# Quick Reference Card

## Essential Commands

```bash
npm run dev        # ⚡ Start dev server (USE THIS FOR DEVELOPMENT)
npm run build      # 📦 Build for production (RARE)
npm run preview    # 👀 Preview production build
```

## Development Loop (99% of the time)

```bash
# 1. Start dev server (ONCE)
npm run dev

# 2. Open browser
http://localhost:3000

# 3. Edit files in src/
#    → Changes appear instantly!
#    → No rebuild needed!

# 4. Repeat step 3 all day
```

## Where to Edit

✅ **Edit these:** `src/` directory
```
src/types/           ← Ordinal types
src/operations/      ← Rules and engines
src/conversions/     ← Type conversions
src/*.js             ← Parser, calculator, UI
```

❌ **Don't edit these:**
```
dist/                ← Generated by npm run build
[root *.js files]    ← Legacy (for compatibility only)
```

## Testing

**During development:**
- Open http://localhost:3000
- Test calculations manually
- Check browser console

**Before committing:**
```bash
npm run build
# Open: tests/ordinal_enf_test_new.html
# Open: tests/ordinal_calculator_test_new.html
```

## Common Tasks

### Add new feature
```
1. Edit src/types/NewFeature.js
2. Check localhost:3000 (auto-updates!)
3. Done!
```

### Fix bug
```
1. Edit src/operations/BuggyFile.js
2. Check localhost:3000 (auto-updates!)
3. Test fix works
4. Done!
```

### Test alertness mode
```
1. Edit src/operations/RuleEngine.js
   Set: static alertnessTestEnabled = true;
2. Check localhost:3000 (auto-updates!)
3. Tests should fail randomly - working!
4. Set back to false
```

### Prepare for deployment
```
npm run build && npm run preview
# Test everything
# If good: git commit && git push
```

## Troubleshooting

**Changes not appearing?**
- Check terminal - is `npm run dev` running?
- Hard refresh: Ctrl+Shift+R

**Module errors?**
- Check import paths have `.js` extension
- Check file exists in src/

**Tests failing?**
- Using production tests? Run `npm run build` first
- Using dev mode? Changes should be instant

## Key Principles

1. **Development = `npm run dev`** (fast, instant feedback)
2. **Production = `npm run build`** (rare, before deploy)
3. **Edit `src/` only** (not dist/ or root .js)
4. **Tests via localhost:3000** (during development)
5. **Tests via *_new.html** (before release)

---

**Remember:** Dev server = instant changes, no rebuild! 🚀
